# Backend Product API – Node.js

Basic REST API developed as part of a backend learning project.

## 🚀 Tech Stack
- Node.js
- Express

## 📌 Endpoints

### Get all products
GET /products

Optional query:
?limit=number

### Get product by ID
GET /products/:pid

## 🎯 Purpose
This project was created to practice backend fundamentals:
- Express server setup
- Routing
- Query params
- Dynamic params
- Basic API structure
